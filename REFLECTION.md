# Reflection

## 1. What is the difference between column and row with flex-direction?

In a flex container, "flex-direction" specifies the main axis of your flex container, the line along which the flex items are placed. The most common direction, "row", which is the default, lines the flex items up horizontally from left to right, with the cross axis running vertically. "column" stacks the elements vertically, with the cross axis running horizontally. This change flips the axes that "justify-content" and "align-items" operate on. In a "row", justify-content spreads items left to right, while align-items does its job in the vertical direction. Conversely, a "column" is the reverse: justify-content handles top to bottom distribution, and align-items aligns left to right. This is the method behind how the navigation is built. On desktop, using flex-direction: row, the logo is aligned left and the links right. At the mobile breakpoint, the switch to "column" allows all elements to stack.

## 2. Why relative units are important in responsive design

Pixels are fixed values that do not change regardless of the size of the device viewing the website. A 900px wide div will extend past a 400px phone screen and cause horizontal scrolling. Relative units are relative to their context and scale with the screen: a percentage is relative to the parent element, viewport height "vh" and width "vw" are relative to the size of the window viewport, and "rem" is relative to the root element's font size. Using relative units, I could have one layout that resizes for all screen sizes rather than creating a new style rule for each size. "rem" also has accessibility implications because it takes into account the font size a user has set in their browser settings. If they change their default font size, the text and spacing on the page scale with it, whereas "px" values will not.
